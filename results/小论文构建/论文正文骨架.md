# 论文正文骨架

## 一、任务包 3 术语判断与统一规则

### 1.1 是否可行

可行，且建议采用该设置：

- 小论文统一使用“选址-分配”作为核心模型术语。
- 大论文统一使用“布局优化”作为章节主题和规划层面表述。
- 小论文中可以在结果解释、规划启示和工程意义部分少量使用“布局方案”“空间布局”“布局优化结果”，但不宜替代“选址-分配模型”。

### 1.2 判断理由

从交通运输与城市物流研究范式看，“布局优化”与“选址-分配”不是完全冲突的术语，而是层级不同。

“布局优化”更偏规划叙述，强调地铁物流配送转运点在空间上的配置状态，适合用于大论文题目、章节标题和整体研究框架。它能够覆盖候选点识别、设施启用、空间分布、服务覆盖、结果解释、规划建议等内容，范围较宽。

“选址-分配”更偏运筹优化建模，强调同时决定“哪些候选转运点被启用”和“末端需求或货流由哪些转运点服务”。本文第四章模型不仅判断转运点是否启用，还涉及 OD 货流分配、地铁联运与公路直送方式选择、站点容量、线路能力、服务半径、换乘次数和地铁服务比例等约束。因此，小论文若突出模型贡献，使用“选址-分配”比“布局优化”更精确。

### 1.3 术语使用规则

| 使用场景 | 推荐术语 | 说明 |
|---|---|---|
| 大论文题目、章节标题、综合叙述 | 布局优化 | 强调规划问题和空间配置结果 |
| 小论文题目、摘要、模型部分 | 选址-分配 | 强调启用决策与需求分配的联合优化 |
| 小论文结果解释 | 布局方案、空间布局、布局优化结果 | 作为“选址-分配模型”的结果表达 |
| 算法求解对象 | 多目标选址-分配模型 | 不写成“多目标布局模型” |
| 案例结论 | 转运点布局方案 | 用于表达方案的工程规划意义 |

### 1.4 统一后的推荐题目

小论文推荐题目：

**面向中心城区配送的地铁物流转运点识别与选址-分配优化**

大论文相关章节可继续使用：

**地铁物流配送转运点布局优化模型构建及算法设计**

二者关系可在小论文中表述为：

本文面向中心城区地铁物流配送场景，构建地铁物流转运点识别与选址-分配优化方法，在候选转运点筛选基础上，联合优化转运点启用决策、末端需求分配关系和地铁联运服务比例，形成可用于中心城区地铁物流转运点布局优化的决策方案。

## 二、论文基本定位

### 2.1 论文题目

面向中心城区配送的地铁物流转运点识别与选址-分配优化

### 2.2 投稿场景

拟面向《交通运输系统工程与信息》投稿，文章应定位为交通运输系统优化与城市物流协同配送研究，不宜写成单纯算法改进论文，也不宜写成学位论文章节压缩稿。

### 2.3 核心研究问题

在中心城区道路配送压力较高、地铁平峰期存在一定剩余运输能力的条件下，如何从地铁站点中识别具备物流转运潜力的候选点，并进一步确定启用转运点、末端需求分配关系和地铁联运服务比例，使系统在综合成本与地铁服务比例之间取得平衡。

### 2.4 核心贡献表述

1. 构建融合地铁网络结构与站域需求潜力的地铁物流转运点识别方法，采用 CRITIC-TOPSIS 筛选候选转运点。
2. 建立面向地铁物流配送的双目标选址-分配模型，同时考虑综合成本最小化与地铁服务比例最大化。
3. 设计强化学习辅助的 QVNS-NSGA-II 求解框架，通过 Q-learning 自适应选择搜索扰动或邻域策略，提高多目标强约束问题的求解稳定性。
4. 以成都武侯区为案例，验证候选点识别、选址-分配优化和折中方案选择方法的适用性。

## 4 多目标选址-分配模型与求解算法

### 4.1 写作目标

这是论文核心部分。应明确“选址-分配”不是单纯空间布局，而是同时决定启用哪些转运点、哪些需求由哪些转运点服务、货流采用地铁联运还是公路直送。

### 4.2 模型假设与符号

应包含：

- 集合：物流园区集合、候选转运点集合、末端需求点集合、地铁线路集合、OD 需求集合。
- 参数：运输成本、固定启用成本、转运成本、站点容量、服务半径、换乘次数、线路班次能力、负载率上下限。
- 决策变量：转运点启用变量、需求分配变量、运输方式选择变量、线路关联变量。

### 4.3 双目标模型

目标函数：

- 综合成本最小化。
- 地铁服务比例最大化。

关键约束：

- 需求唯一服务或分配约束。
- 末端配送距离不超过 4 km。
- 最大换乘次数不超过 2 次。
- 转运点容量约束。
- 地铁负载率 15%-85%。
- 候选转运点最小间距 2 km。
- 每条地铁线路最多启用 3 个转运点。
- 平峰期可用货运班次能力约束。

### 4.4 QVNS-NSGA-II 求解算法

算法定位：

QVNS-NSGA-II 是服务于多目标选址-分配模型的求解工具，而不是本文唯一贡献。强化学习的作用是根据搜索状态自适应选择邻域或扰动策略，提高强约束离散多目标问题的搜索效率。

应写内容：

- NSGA-II 负责多目标种群进化与非支配排序。
- VNS 负责围绕启用点替换、需求重分配、服务方式切换等邻域进行局部改进。
- Q-learning 负责根据搜索状态选择邻域动作。
- 外部档案用于保存非支配解。
- 可行性修复或安全回滚用于处理约束违反。

强化学习合理性表述：

地铁物流选址-分配问题中，启用转运点组合、需求分配和运输方式选择相互耦合，不同搜索阶段适用的邻域操作不同。引入 Q-learning 对邻域动作进行自适应调度，可以减少固定邻域策略对人工经验的依赖，并提高 Pareto 解集质量和稳定性。
