# 参考文献支撑与 GB/T 7714 清单

## 一、下一步分析内容

本阶段工作的重点不是简单补一组参考文献，而是为小论文《面向中心城区配送的地铁物流转运点识别与选址-分配优化》建立可核验的文献支撑链。建议下一步围绕以下四类论断补强正文引用。

1. 城市物流与中心城区配送问题背景：支撑“城市货运对拥堵、环境、道路空间和生活质量产生影响”“城市物流需要在效率与外部性之间权衡”等基础论断。
2. 地铁/城市轨道交通参与城市货运的可行性与约束：支撑“公共交通基础设施可用于货物运输”“地铁物流需要考虑客货协同、时刻表、站点装卸、容量、安全与组织约束”等论断。
3. 转运点识别与选址-分配模型：支撑“候选点评价不能直接等同最终启用方案”“选址-分配需要同时决定设施启用与需求分配”“网络中心性可刻画站点结构位置”等论断。
4. 方法与算法合理性：支撑“CRITIC 可用于客观赋权”“TOPSIS 可用于多属性方案排序与折中解选择”“NSGA-II 适合多目标优化”“VNS 适合组合优化局部搜索”“Q-learning 可用于自适应动作选择”等论断。

## 二、关键论断与支撑文献

|论文位置|建议支撑的关键论断|可用文献|
|---|---|---|
|引言第1段|城市货运支撑城市运行，但也带来拥堵、污染、噪声和道路空间占用等外部性。|Taniguchi 等[1]；Crainic 等[2]；Savelsbergh 与 Van Woensel[3]|
|引言第2段|城市物流研究正从单一道路配送转向多式联运、多层级网络和公共交通协同。|Savelsbergh 与 Van Woensel[3]；Elbert 与 Rentschler[7]|
|引言/问题描述|利用城市轨道/公共交通网络运输货物具有潜力，但必须处理乘客服务、运能、站点装卸和组织协调约束。|Dampier 与 Marinov[4]；Behiri 等[5]；Ozturk 与 Patrick[6]；Li 等[8]|
|问题描述与模型边界|地铁物流/地下物流系统具有缓解道路交通压力的潜力，但建设、组织和运营约束需要纳入规划。|Chen 等[9]；Dong 等[10]；Hu 等[11]|
|转运点识别方法|用网络中心性刻画站点在轨道网络中的连接、桥接和可达作用具有方法基础。|Freeman[12]；Opsahl 等[13]；Newman[14]|
|选址-分配模型|选址-分配问题的核心是同时确定设施位置与需求分配关系，适合表达“启用哪些转运点、服务哪些需求点”。|Cooper[15]；Daskin[16]|
|CRITIC-TOPSIS|CRITIC 可根据指标对比强度和冲突性客观确定权重；TOPSIS 可基于理想解距离进行排序。|Diakoulaki 等[17]；Hwang 与 Yoon[18]|
|多目标求解|NSGA-II 是经典多目标进化算法，适合生成成本-服务等多目标权衡解集。|Deb 等[19]|
|QVNS-NSGA-II 设计|VNS 通过系统改变邻域结构强化局部搜索，适合组合优化；Q-learning 可用于根据状态-动作回报更新动作选择策略。|Mladenović 与 Hansen[20]；Hansen 与 Mladenović[21]；Watkins 与 Dayan[22]|

## 四、不确定信息与处理说明

1. Taniguchi 等[1] 为专著，部分数据库给出的出版地存在 Oxford、Amsterdam 等差异。本文暂按常见引用方式著录为 Oxford: Pergamon, 2001；正式投稿前建议以馆藏记录或原书版权页为准。
2. Daskin[16] 用于支撑离散选址模型的一般理论，不是地铁物流专门文献。如篇幅紧张，可保留 Cooper[15] 作为选址-分配经典来源，Daskin[16] 作为方法类补充文献。
3. 中文数据库文献尚未纳入本轮清单。由于 CNKI/万方元数据未在本次联网检索中完成核验，不建议当前编造中文文献条目；若后续需要增强国内研究述评，应单独检索并核对中文题名、作者、期刊、年卷期页码。
