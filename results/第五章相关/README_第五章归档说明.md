# 第五章相关资料归档说明

本文件夹用于集中保存第五章最终版 Word、最终图件、绘图脚本、数据生成脚本和复现实验数据。归档采用复制方式完成，未移动或删除原始项目文件。

## 目录结构

- `01_最终Word/`：第五章最终 Word 文件。
- `02_最终图片/01_Word嵌入图片/`：从最终 Word 中提取的全部嵌入图片，保留 `image*.png` 原始媒体编号。
- `02_最终图片/02_命名图件/`：已命名的最终图件输出，包括图 5-1、图 5-4 和图 5-6 三联图。
- `03_绘图代码/`：用于统一图件风格、重绘图 5-1、图 5-4 和图 5-6 的脚本。
- `04_生成数据代码/01_模型与算法代码/`：布局优化、算法求解、TOPSIS 选择和基础绘图工具代码。
- `04_生成数据代码/02_第五章文档与数据处理脚本/`：第五章正文、表格、图件和参数补强相关脚本。
- `04_生成数据代码/03_实验批处理脚本/`：消融实验和批量求解相关脚本。
- `05_数据/01_基础空间与参数数据/`：地铁站点、线路、行政边界、顺丰需求点、矩阵数据和模型参数。
- `05_数据/02_候选站点评价与阶段1图件数据/`：CRITIC-TOPSIS 候选站点评价结果和阶段1候选识别图件数据。
- `05_数据/03_三类偏好空间布局结果/`：成本偏好、均衡偏好、服务偏好方案的空间分配、站点负载和权重情景 TOPSIS 结果。
- `05_数据/04_均衡方案与基准对比结果/`：均衡代表方案、全公路基准方案、线路负载、站点负载和敏感性分析结果。
- `05_数据/05_算法对比与消融实验结果/`：多算法对比和 QVNS-NSGA-II 消融实验结果。
- `05_数据/06_QGIS4524图5-1输入数据/`：图 5-1 使用的 EPSG:4524 QGIS 栅格、边界、线路和站点输入文件。
- `06_说明清单/`：归档文件清单。

## 复现提示

主要重绘入口脚本位于 `03_绘图代码/`：

- `regenerate_ch5_figures.py`：批量重绘已统一风格的第五章主要图件并替换 Word 媒体。
- `plot_fig5_1_from_qgis4524.py`：使用 QGIS EPSG:4524 数据重绘图 5-1。
- `plot_fig5_4_6_triptych.py`：重绘图 5-4 单图和图 5-6 三联图，并写回 Word。
- `sync_triptych_docx_text.py`：同步图 5-6 三联图对应正文说明和图题。

如需完全复现，应在项目包根目录运行脚本，并确认 Python 环境已安装 `geopandas`、`pandas`、`matplotlib`、`Pillow`、`rasterio`、`pyproj` 等依赖。
