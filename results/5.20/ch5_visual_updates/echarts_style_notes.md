# ECharts 参考风格与本次图件规范

## 参考来源

- ECharts 示例页：https://echarts.org.cn/examples/en/index.html
- 页面截图：`echarts_examples_reference.png`
- OCR 识别到的图表类型关键词：Line, Bar, Pie, Scatter, Graph, Lines, Heatmap, Stacked Line, Basic Line Chart, Gradient Stacked Area Chart

## 提取到的视觉特征

- 页面整体采用白色背景、弱灰坐标轴和网格线，适合论文插图打印。
- 字体层级接近 `"Open Sans", "PingFang SC", Helvetica, Arial, sans-serif`；本机绘图字体选择为 `Microsoft YaHei`。
- 分类配色参考 ECharts 常用蓝、绿、黄、红、青、紫色系，并降低装饰性饱和度。
- 图例统一靠上或靠右，坐标轴保留四边框，避免网页仪表盘式重装饰。
