# 第四章相关资料归档说明

本文件夹用于集中保存第四章最终版 Word、最终图件、模型与算法代码、参数数据和支撑说明。归档采用复制方式完成，未移动或删除原始项目文件。

## 目录结构

- `01_最终Word/`：第四章最终修订版 Word 文件，仅保留最终版本。
- `02_最终图片/01_Word嵌入图片/`：从最终 Word 中提取的嵌入图片，保留 `image*.png` 等媒体编号。
- `02_最终图片/02_命名图件/`：第四章已命名最终图件，包括图 4-1 至图 4-5 的 PNG、SVG、PDF 文件。
- `03_绘图代码/`：图件绘制和中文字体处理相关脚本。
- `04_生成数据代码/01_模型与算法代码/`：QVNS-NSGA-II、NSGA-II、TOPSIS 场景选择和候选点评价相关脚本。
- `04_生成数据代码/02_第四章文档与算法图处理脚本/`：文档和算法图处理的辅助脚本。
- `05_数据/01_基础参数数据/`：模型全局参数、平峰期班次、装载能力和物流园区货源比例等参数数据。
- `05_数据/02_候选转运点与线路关联数据/`：候选转运点属性表和路径线路关联矩阵。
- `06_说明清单/`：算法设计说明、模型参数口径核查、算法流程图源文件和归档文件清单。

- `物流园区货源比例与接入信息.csv`：物流园区货源比例和接入信息。
- `候选转运点最终属性表.csv`：候选转运点属性、类型、能力和成本等模型输入。
- `路径线路关联矩阵_a_ik_line.csv`：路径与线路关联矩阵。
