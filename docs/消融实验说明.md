# QVNS-NSGA-II 消融与增强参数调优实验说明

本脚本用于在同一实验框架下比较基础消融组与增强型 QVNS 参数组。基础消融组用于验证 Q-learning 与 VNS 两个模块的边际贡献；增强参数组用于在 QVNS-Q3 的基础上进一步改善 Spacing、HV 稳定性、IGD、Spread、唯一解数和运行时间。

## 1. 基础消融组

| 组别 | Q-learning | VNS | 说明 |
|---|---:|---:|---|
| NSGA-II | × | × | 基准多目标遗传算法 |
| VNS-only | × | √ | 验证 VNS 局部搜索贡献 |
| Q-learning-only | √ | × | 验证 Q-learning 扰动选择贡献 |

## 2. 默认增强型 QVNS 调优组

当前默认运行组为 Q3、Q9、Q9A、Q9B、Q9C、Q9D、Q11、Q11A、Q11B、Q11C。其中 Q11C 是当前 QVNS-NSGA-II 的最终默认配置。

| 组别 | vns_mode | elite_rate | trials | max_neighborhood | epsilon_end | archive倍率 | boundary_keep_rate | 目标 |
|---|---|---:|---:|---:|---:|---:|---:|---|
| Q3 | fixed | 0.18 | 4 | 4 | 0.020 | 2.0 | 0.00 | 平衡 HV 与运行时间的基础基准 |
| Q9 | adaptive | 0.12 | 2 | 3 | 0.020 | 2.5 | 0.20 | 自适应 VNS 基准，缩短运行时间并保持 HV |
| Q9A | adaptive | 0.10 | 2 | 3 | 0.020 | 2.0 | 0.18 | 快速分支，减少 VNS 调用并改善运行时间 |
| Q9B | adaptive | 0.12 | 2 | 3 | 0.008 | 2.5 | 0.20 | 稳定分支，降低后期随机性和 HV 标准差 |
| Q9C | adaptive | 0.14 | 2 | 3 | 0.020 | 4.0 | 0.30 | 多样性分支，扩大 archive 并改善 Spacing/Spread |
| Q9D | adaptive | 0.15 | 3 | 4 | 0.012 | 3.0 | 0.25 | 综合质量分支，兼顾 HV、IGD、Spread 与运行时间 |
| Q11 | adaptive | 0.18 | 3 | 4 | 0.008 | 3.5 | 0.25 | 综合增强基准 |
| Q11A | adaptive | 0.16 | 3 | 4 | 0.005 | 3.0 | 0.18 | 稳定收敛：降低 HV 标准差和 IGD 波动 |
| Q11B | adaptive | 0.18 | 3 | 4 | 0.012 | 5.0 | 0.35 | 分布多样性：改善 Spacing/Spread，提高唯一解数 |
| Q11C | adaptive | 0.12 | 2 | 3 | 0.010 | 2.5 | 0.20 | 快速综合：减少 VNS 调用并保持综合质量 |

说明：

- `archive_size` 由各组的 archive 倍率与 `pop_size` 相乘得到，用于保存搜索过程中产生的非支配解；
- `boundary_keep_rate` 会在 archive 截断和 VNS 候选选择时保留成本端与服务端边界解；
- `vns_mode=adaptive` 表示只有当最近若干代 HV 改进低于阈值时才触发 VNS，以减少无效局部搜索；
- 旧 Q1–Q8/Q10 仍可复现实验，但默认运行组切换为 Q3、Q9、Q9A、Q9B、Q9C、Q9D、Q11、Q11A、Q11B、Q11C。

## 3. 推荐运行命令

一次性同时运行基础消融组与默认 Q9/Q11 分支调优组：

```bash
python scripts/run_qvns_ablation_experiment.py --comparison-mode all --pop-size 100 --max-gen 300 --runs 10 --quiet
```

只运行基础消融组：

```bash
python scripts/run_qvns_ablation_experiment.py --comparison-mode ablation --pop-size 100 --max-gen 300 --runs 10 --quiet
```

只运行增强型 QVNS 调优组：

```bash
python scripts/run_qvns_ablation_experiment.py --comparison-mode tuning --qvns-tuning-groups Q3 Q9 Q9A Q9B Q9C Q9D Q11 Q11A Q11B Q11C --pop-size 100 --max-gen 300 --runs 10 --quiet
```

若需复现旧调优组：

```bash
python scripts/run_qvns_ablation_experiment.py --comparison-mode tuning --qvns-tuning-groups Q1 Q2 Q3 Q4 Q5 Q6 --pop-size 100 --max-gen 300 --runs 10 --quiet
```

脚本默认启用断点续跑，完成一个组合就即时保存 CSV/SVG；中断后重新执行同一命令会自动跳过已完成组合。若需要重跑全部组合，加 `--no-resume`。

## 4. 输出文件

默认输出目录：

```text
results/qvns_ablation/
```

主要输出：

| 文件 | 含义 |
|---|---|
| `ablation_summary.csv` | 各算法/调优组的均值汇总，包括 HV、IGD、Spread、Spacing、唯一解数量、最小成本、最大服务比、TOPSIS 指标、VNS 调用次数和 archive 规模 |
| `ablation_run_metrics.csv` | 每次独立运行的详细指标，并记录 QVNS 调优参数 |
| `ablation_pareto_points.csv` | 每次运行的 Pareto 点 |
| `fig_ablation_pareto_no_budget_range.svg` | Pareto 前沿对比图 |
| `fig_ablation_hv_no_budget_range.svg` | HV 对比图 |
| `fig_ablation_igd_no_budget_range.svg` | IGD 对比图 |
| `fig_ablation_spread_no_budget_range.svg` | Spread 对比图 |
| `fig_ablation_spacing_no_budget_range.svg` | Spacing 对比图 |
| `fig_ablation_min_cost_no_budget_range.svg` | 最小成本对比图 |

## 5. 中文字体说明

消融实验可视化输出为 SVG，已内置中文字体回退列表。若打开图件时中文显示为方框，请在本机安装或指定中文字体：`QVNS_SVG_FONT=Microsoft YaHei` 或 `QVNS_SVG_FONT=Noto Sans CJK SC`。

## 6. Q11 分支说明

Q11 分支用于拆解综合增强组中的 archive、边界保留、自适应 VNS 和后期稳定控制机制。Q11C 是当前最终采用的快速综合配置，对应 `alpha=0.15`、`gamma=0.88`、`epsilon_min=0.010`、`vns_elite_rate=0.12`、`vns_trials_per_neighborhood=2`、`vns_max_neighborhood=3`、`archive_size=2.5×pop_size`、`boundary_keep_rate=0.20`、`stagnation_window=10`、`hv_improvement_threshold=0.0025`、`min_vns_gap=5`。
