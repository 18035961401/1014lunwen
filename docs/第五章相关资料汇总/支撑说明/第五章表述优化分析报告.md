# 第五章表述优化分析报告

## 一、总体判断

`第五章_成都市武侯区地铁物流配送转运点布局优化研究.docx` 的内容总体较完整，已经能够支撑论文第五章实证研究部分。章节覆盖了案例区域与基础数据、第一阶段备选转运点识别、第二阶段布局优化与方案分析、算法性能对比、敏感性分析和本章小结，结构与前文“两阶段研究框架”基本一致。

从写作质量看，第五章具备以下优点：

1. 案例区域、基础数据、候选点、需求点、物流园区和线路能力等基础要素交代较充分；
2. 能够承接第三章 CRITIC-TOPSIS 站点评价结果，并进入第四章选址—分配模型；
3. 对 QVNS-NSGA-Ⅱ 的求解结果、折中方案、站点负载、线路班次利用和碳减排效果均有解释；
4. 敏感性分析覆盖需求规模、成本参数和货源比例三个方向，能够支撑结果稳健性分析；
5. 本章小结能够概括主要结果和管理启示。

因此，该章不是“需要重写”，而是“建议进行表述优化和单位口径统一”。重点优化对象是表头单位、术语一致性、部分结论措辞和与第三、四章的衔接方式。

## 三、需要优化的主要问题

### 1. 表头单位口径需要统一

当前表格中存在 `元日`、`件日`、`元趟` 等压缩写法，例如：

- `平峰总容量/件日`
- `处理能力/件日`
- `固定成本/元日`
- `最低成本/元日`
- `班次组织成本/元趟`

建议统一为更规范的写法：

| 当前写法 | 建议写法 |
|---|---|
| 件日 | 件/日 |
| 元日 | 元/日 |
| 元趟 | 元/趟 |
| 平峰总容量/件日 | 平峰总容量/件/日 或 平峰总容量（件/日） |
| 固定成本/元日 | 固定成本（元/日） |
| 最低成本/元日 | 最低成本（元/日） |
| 班次组织成本/元趟 | 班次组织成本（元/趟） |

这属于文字口径问题，不涉及数值修改。

### 2. 碳排放单位建议统一

正文中出现 `tCO₂/日`，而你前面已经确认论文统一口径为 `kgCO₂`。建议第五章统一为 `kgCO₂/日`，或者在表格中保留吨时写为 `tCO₂/日` 并明确“为便于展示，表中碳排放按 tCO₂/日列示”。

更推荐统一写为：

> 碳排放量单位统一为 kgCO₂；若表格采用 tCO₂ 展示，应在表注中说明 1 tCO₂ = 1000 kgCO₂。

如果要与前文完全一致，建议将表 5-9 的 `碳排放（tCO₂/日）` 改为 `碳排放（kgCO₂/日）`，并相应把数值乘以 1000。但如果不想改数值，则保留 `tCO₂/日`，但必须加注说明。

### 3. Q11 与 Q11C 口径需要统一

第四章终稿中曾提到最终采用 `Q11C` 作为主算法参数组，而第五章当前多处写作 `Q11 参数配置`。如果你最终算法参数组名称确定为 `Q11`，第四章应同步改为 `Q11`；如果最终名称是 `Q11C`，则第五章应统一改为 `Q11C`。

建议优先选择一种命名并全文统一。根据当前第五章内容，建议统一为：

> Q11 综合增强参数配置

除非第五章表格或补充数据明确区分 Q11A、Q11B、Q11C，否则不建议突然使用 Q11C。

### 4. “更优”“均表现更优”等结论需要更审慎

本章小结中写到 QVNS-NSGA-Ⅱ 在 HV、IGD、最低成本和最大服务比例等指标上“均表现更优”。从表 5-10 看，QVNS-NSGA-Ⅱ 的 HV、IGD、最低成本、最大服务比例确实较好，但其平均运行时间高于 NSGA-Ⅱ、MOPSO 和 MOEA/D。因此建议写成：

> QVNS-NSGA-Ⅱ 在 HV、IGD、最低成本和最大服务比例等解集质量指标上表现较优，但运行时间相对增加，体现出以计算时间换取前沿质量和搜索稳定性的特征。

这样更严谨，避免被评审认为忽略了运行效率代价。

### 5. “显著”类表述建议适度弱化

例如“货源比例变化对综合成本的影响较为显著”。如果没有统计显著性检验，建议避免使用“显著”作为统计意义表达，可改为：

> 货源比例变化对综合成本具有较明显影响。

或：

> 货源比例变化会明显改变前端接入距离和地铁路径结构，从而影响综合成本。

### 6. 5.2 与第三章的衔接可再明确

5.2.1 中写“综合考虑站点线路属性、换乘属性、交通可达性、空间覆盖能力和末端需求邻近性等因素”，但第三章实际指标侧重为：

- 网络结构：度中心性、介数中心性、接近中心性、特征向量中心性；
- 需求潜力：人口密度、住宅数量、城市零售集群数量、香农熵。

建议第五章改成与第三章一致的表述：

> 本文沿用第三章构建的网络结构与需求潜力协同评价框架，从地铁网络拓扑中心性和站域需求潜力两个维度对武侯区地铁站点进行综合评价。其中，网络结构维度包括度中心性、介数中心性、接近中心性和特征向量中心性，需求潜力维度包括人口密度、住宅数量、城市零售集群数量和功能结构混合度。

这样能避免第五章和第三章指标口径不完全一致。

### 7. 5.3 成本构成与第四章口径需要完全一致

5.3.1 中成本构成整体清晰，但建议与第四章保持如下术语：

- 固定启用成本；
- 公路直送运营成本；
- 物流园区至地铁接入站接入成本；
- 地铁干线运输成本；
- 换乘作业成本；
- 进出站作业成本；
- 末端接驳成本；
- 碳成本；
- 平峰期班次组织成本。

如果正文中出现“接驳成本”“接入成本”混用，建议统一区分：

- 前端：物流园区至地铁接入站，称“接入运输”；
- 末端：候选转运点至需求点，称“末端接驳”。

### 8. 表 5-1 与“候选转运点数量”表述需注意

表 5-1 中写“候选转运点数量 17 个”，但 5.1.1 中写“案例数据覆盖武侯区地铁站点 51 个”。建议明确区分：

- 参与第一阶段评价的地铁站点：51 个；
- 经 CRITIC-TOPSIS 筛选进入第二阶段模型的备选转运点：17 个。

否则读者可能误以为案例区域只有 17 个地铁站点。

### 9. 表格标题与正文引用建议补齐

当前提取结果显示有 13 个表，但 Word 中表题可能以普通段落存在。建议检查是否每个表前均有规范表题，如：

同时建议所有表格在正文中都有解释，不要只堆表。当前多数表已有解释，但表 5-1、表 5-2、表 5-3、表 5-4 可适当补充“数据作用”，说明它们分别服务于需求测算、物流源点设置和接入站确定。
