# 5.1 地铁物流转运点选址—分配双目标模型


## 1. 模型定位


本文构建无预算约束下的地铁物流转运点选址—分配双目标模型。固定成本进入综合成本目标，但不再设置固定成本预算上下限。模型以“物流园区—顺丰站点”为不可拆分货流单元，在 4 km 服务边界内尽可能提高地铁服务比例，服务边界外或受约束无法承接的货流由公路运输完成。


## 2. 集合


| 符号 | 含义 |

|---|---|

| \(I\) | 物流园区集合 |

| \(J\) | 顺丰需求站点集合 |

| \(K\) | 候选地铁转运点集合 |

| \(L\) | 地铁线路集合 |

| \(R_\ell\) | 线路 \(\ell\) 平峰期可用货运班次集合，本文设 \(|R_\ell|=5\) |


距离过近的候选转运点对不单独定义集合，直接在最小间距约束中使用 \(\Delta_{kh}<\overline{\Delta}\) 判断。


## 3. 参数


| 符号 | 代码变量 | 含义 |

|---|---|---|

| \(q_{ij}\) | `source_share[i] * Q_j[j]` | 物流园区 \(i\) 至顺丰站点 \(j\) 的不可拆分货流量 |

| \(F_k\) | `fixed_cost` | 转运点固定启用成本 |

| \(U_k\) | `station_capacity` | 转运点平峰作业周期处理能力 |

| \(\underline{\rho}\) | `min_load_rate` | 转运点最低负载率，取 0.15 |

| \(\overline{\rho}\) | `max_load_rate` | 转运点最高负载率，取 0.85 |

| \(d^R_{ij}\) | `d_ij_road` | 物流园区至顺丰站点公路距离 |

| \(d^A_i\) | `d_is_road` | 物流园区至接入地铁站公路接入距离 |

| \(d^M_{ik}\) | `d_metro` | 物流园区接入站至候选转运点的地铁运输总距离 |

| \(d^F_{kj}\) | `d_kj_road` | 候选转运点至顺丰站点末端接驳距离 |

| \(D_k\) | `D_k_max` | 最大末端接驳距离，取 4 km |

| \(\tau_{ik}\) | `transfer_count` | 物流园区接入站至转运点路径换乘次数 |

| \(\overline\tau\) | `max_transfer_count` | 最大允许换乘次数，取 2 |

| \(\sigma_{k\ell}\) | 由站点所属线路生成 | 转运点 \(k\) 是否属于线路 \(\ell\) |

| \(a_{ik\ell}\) | `path_line_incidence` | 物流园区 \(i\) 经转运点 \(k\) 的路径是否占用线路 \(\ell\) |

| \(G_\ell\) | `line_capacity` | 线路 \(\ell\) 单趟列车货运容量 |

| \(\overline X_\ell\) | `max_open_per_line` | 每条线路最多允许设置的转运点数量，取 3 |

| \(\eta\) 或 \(\theta^{fre}\) | `train_organization_cost_rate` | 满载分摊的平峰期货运班次组织成本率，取 0.06 元/件 |

| \(\lambda^C\) | `carbon_price` | 碳价格，取 0.10 元/kgCO₂ |

| \(e^R,e^M,e^E\) | 排放因子 | 公路、地铁、末端接驳单位件公里排放因子 |


转运点容量按站点类型确定：


\[

U_k=\begin{cases}

5000, & k\in K^{SL}\\

7000, & k\in K^{TR}\\

10000, & k\in K^{HB}

\end{cases}

\]


其中，\(K^{SL}\) 为小型站，\(K^{TR}\) 为换乘站，\(K^{HB}\) 为枢纽站。列车容量来自“平峰期地铁货运体积与装箱能力参数.csv”，该表基于有效体积的 20% 和标准箱三维整数排布计算单趟列车可装箱数。


## 4. 决策变量


| 变量 | 含义 |

|---|---|

| \(x_k\in\{0,1\}\) | 是否启用候选转运点 \(k\) |

| \(z_{ijk}\in\{0,1\}\) | 货流 \(q_{ij}\) 是否整体分配至转运点 \(k\) |

| \(o_{ij}\in\{0,1\}\) | 货流 \(q_{ij}\) 是否由公路运输完成 |

| \(y_{ijk\ell r}\in\{0,1\}\) | 货流 \(q_{ij}\) 经转运点 \(k\) 后是否装入线路 \(\ell\) 第 \(r\) 趟列车 |

| \(w_{\ell r}\in\{0,1\}\) | 线路 \(\ell\) 第 \(r\) 趟列车是否被用于货运组织 |


代码实现中保持原有染色体结构，即 \(x_k\) 与货流分配编码；列车班次变量通过评价函数中的不可拆分装箱校验实现。


## 5. 目标函数


### 5.1 综合成本最小化


\[

\min Z_1=C^F+C^R+C^A+C^M+C^{TR}+C^{IO}+C^L+C^C+C^{OC}

\]


其中：


\[

C^F=\sum_{k\in K}F_kx_k

\]


\[

C^R=\sum_{i\in I}\sum_{j\in J}q_{ij}c^Rd^R_{ij}o_{ij}

\]


\[

C^A=\sum_{i,j,k}q_{ij}c^Ad^A_iz_{ijk}

\]


\[

C^M=\sum_{i,j,k}q_{ij}c^Md^M_{ik}z_{ijk}

\]


地铁运输成本不拆分线路距离，直接使用接入地铁站至候选转运点的总地铁运输距离矩阵 \(d^M_{ik}\)。


\[

C^{TR}=\sum_{i,j,k}q_{ij}c^{TR}\tau_{ik}z_{ijk}

\]


\[

C^{IO}=\sum_{i,j,k}q_{ij}c^{IO}z_{ijk}

\]


\[

C^L=\sum_{i,j,k}q_{ij}c^Ld^F_{kj}z_{ijk}

\]


碳成本由排放因子与碳价格统一生成：


\[

C^C=\sum_{i,j}q_{ij}(e^R\lambda^C)d^R_{ij}o_{ij}

+\sum_{i,j,k}q_{ij}(e^R\lambda^C)d^A_iz_{ijk}

+\sum_{i,j,k}q_{ij}(e^M\lambda^C)d^M_{ik}z_{ijk}

+\sum_{i,j,k}q_{ij}(e^E\lambda^C)d^F_{kj}z_{ijk}

\]


平峰期货运班次组织成本为：


\[

C^{OC}=\sum_{\ell\in L}\sum_{r\in R_\ell}\eta G_\ell w_{\ell r}

\]


该成本表示既有平峰客运列车参与货运时产生的站台协调、人员调度、货物交接与车厢空间占用成本，不表示整列车完整运行成本。


时间成本和公路直送处理成本不进入目标函数。时间指标保留为运行统计，不折算为货币成本。


### 5.2 全局地铁服务比例最大化


\[

\max Z_2=\frac{\sum_{i,j,k}q_{ij}z_{ijk}}{\sum_{i,j}q_{ij}}

\]


地铁覆盖率针对全局总需求计算，但 4 km 是地铁服务边界，因此全局覆盖率由 4 km 空间覆盖率与服务圈内需求满足率共同决定。


## 6. 约束条件


### 6.1 货流不可拆分


\[

o_{ij}+\sum_{k\in K}z_{ijk}=1,\quad \forall i,j

\]


### 6.2 转运点启用


\[

z_{ijk}\le x_k,\quad \forall i,j,k

\]


### 6.3 4 km 服务边界


\[

d^F_{kj}z_{ijk}\le D_k,\quad \forall i,j,k

\]


### 6.4 换乘次数


\[

\tau_{ik}z_{ijk}\le \overline\tau,\quad \forall i,j,k

\]


### 6.5 转运点处理能力


\[

\underline\rho U_kx_k\le \sum_{i,j}q_{ij}z_{ijk}\le \overline\rho U_kx_k,\quad \forall k

\]


### 6.6 每条线路最多 3 个转运点


\[

\sum_{k\in K}\sigma_{k\ell}x_k\le 3,\quad \forall \ell

\]


### 6.7 转运点最小间距


\[

x_k+x_h\le 1,\quad \forall k,h\in K, k<h, \Delta_{kh}<\overline\Delta

\]


### 6.8 路径与线路班次关联


\[

\sum_{r\in R_\ell}y_{ijk\ell r}=a_{ik\ell}z_{ijk},\quad \forall i,j,k,\ell

\]


### 6.9 单趟列车容量


\[

\sum_{i,j,k}q_{ij}y_{ijk\ell r}\le G_\ell w_{\ell r},\quad \forall \ell,r

\]


### 6.10 班次启用顺序


\[

w_{\ell,r+1}\le w_{\ell r},\quad \forall \ell,r=1,\ldots,|R_\ell|-1

\]


## 7. 结果解释指标


| 指标 | 公式 | 含义 |

|---|---|---|

| 全局地铁服务比例 | \(\sum q_{ij}z_{ijk}/\sum q_{ij}\) | 全部需求中由地铁服务的比例 |

| 4 km 空间覆盖率 | \(Q^{4km}/Q^{total}\) | 已启用转运点 4 km 服务圈覆盖的全局需求比例 |

| 4 km 内需求满足率 | \(\sum q_{ij}z_{ijk}/Q^{4km}\) | 4 km 内需求中实际被地铁服务的比例 |

| 班次使用数量 | \(\sum w_{\ell r}\) | 平峰期实际使用的货运班次数 |

| 最大班次负载率 | \(\max_{\ell,r}\sum qy/G_\ell\) | 单趟列车装载压力 |
